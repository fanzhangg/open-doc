            What it can do

            Every agent reads the doc it works on.

            Details and rules behind its persona, added to its prompt: what to do, what to leave alone, how to reply. Optional.

            Advanced

            Effort How hard it thinks before it answers. Low is fastest.

            Codex works in its own sandbox, without your Codex settings or MCP servers. In the doc's folder it reads only the doc and its comments, and edits the doc only with Auto Editor. Elsewhere it can read files on this computer, except keys and secrets. Sign in once with codex login in a terminal.
