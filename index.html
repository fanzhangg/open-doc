Nightly build · early preview

OpenDoc is a desktop app. Open this page on your Mac or Windows PC to download it.

macOS

For your computer

Apple Silicon Macs (M1 or later)

Download for Mac

OpenDoc-0.1.0-arm64.dmg · 137 MB

Install

  1. Open the downloaded file and drag OpenDoc into Applications.
  2. Open OpenDoc from Applications. The first time, macOS asks if you're sure — click Open.
Not sure which Mac you have?

Apple menu → About This Mac. If it says Chip: Apple M…, this download works. Intel Macs aren't supported yet.

Windows

For your computer

Windows 10 or 11, 64-bit

Download for Windows

OpenDoc.Setup.0.1.0.exe · 123 MB

Install

  1. Run the downloaded installer.
  2. If Windows shows “Windows protected your PC”, click More info, then Run anyway.
  3. Follow the installer and open OpenDoc from the Start menu.

The warning appears because this preview isn't code-signed yet.
